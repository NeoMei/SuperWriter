# SuperWriter v0.2.0 发布后全面审查

## 范围与结论

审查基线为已发布的 `67d1d6a`（v0.2.0），修复位于 `codex/superwriter-audit-020`。本次核对协作写作计划全部 8 个任务、设计全部 10 项验收标准，并审查状态模型、持久化、迁移、安装、HTTP 服务、HTML 交互及原生交付验收。旧版入口和已有交付样例也纳入回归。

所有操作使用仓库内模拟样例或一次性工作区。真实宿主未升级，GitHub 发布未改变；本报告不把模拟批准描述为真实用户确认。8 月历史计划保留原始记录，不根据旧复选框推断本次仍有任务未实现。

本次任务审查、代码审查、修复与功能验证均已完成。多轮独立复审及最终回归未留下已知、可复现且值得修复的未解决问题；最终源码、完整交付套件及真实依赖隔离安装验收全部通过。补丁仅在本地审查分支，尚未合入 main 或发布。

## 多轮审查与修复

### 状态模型与交付条件

大纲新增、删除或重排章节后，保留旧章节曾可能恢复旧配图集合、合稿和排版的批准。第二轮独立审查进一步复现“再次保存相同重排大纲”仍会恢复旧批准。修复将集合恢复条件绑定该精确版本登记时的大纲组成，并在交付入口重新检查必需章节依赖。第三轮用原始复现脚本及完整重新审阅流程复验通过。另修复畸形事件枚举触发未处理异常的问题。

### 安装事务

安装期间收到 TERM/INT/HUP，可能在旧宿主树移入备份后直接清理备份；显式失败回滚期间也存在信号窗口。现在退出会完成回滚，回滚期间忽略终止信号，根据真实移动结果协调恢复。测试实际注入五处信号边界及失败回滚期间的信号，核对宿主树和路由字节完全恢复；独立复审通过。

### 审阅服务与 HTML

修复空闲预连接阻塞整个服务、畸形请求导致连接中断、单图图题/位置未解析、历史图片显示成二进制文本、旧版本图片地址读到新字节、重复点击、异步旧图片覆盖新画面等问题。提交已落盘但刷新失败时明确显示“已记录”；响应不确定时要求先核对，避免错误宣称未保存。并发批准保持只提交一次。前后端独立复审通过，随后完成真实浏览器交互复测。

### PDF 与原生长文验收

此前仅检查 DOCX 嵌图，PDF 删除、替换图片或留下未绘制资源仍可能通过；第二轮还复现不透明覆盖物遮住原图的漏检。现在同时核对批准源图、实际 PDF 图像及页面渲染区域。新增 PyMuPDF 环境要求，缺失时明确失败，不自动安装或跳过。

五页真实 WPS 输出暴露了原生目录、运行页眉和分节页码的合法格式误报。现在依据 DOCX 字段与页面位置核对目录顺序、实际章节页号、标题页眉及连续页脚，正文数字继续严格检查。第二轮发现的额外末尾正文数字漏检也已修复。测试包含真实输出正例及删图、替图、覆盖、错页码、改目录、增删正文等反例。

完整 shell 回归另外发现旧“合法转换图片”夹具只更新了源图/DOCX，没有同步 PDF；按新的严格验证，这些样本确实无效。修复夹具同步构建，保留专门的过时 PDF 反例。

最后一轮合法 JPEG 测试暴露不同解码器与栅格重采样引起的误报。源图与内嵌图使用同一 PDF 解码器，可见区域与同位置、同矩阵渲染的参考图比较，保留原像素阈值及源图匹配要求。独立复审再次执行原始遮挡、额外数字探针和 14 项测试，并另外验证合法 JPEG 通过、JPEG 遮挡和像素篡改拒绝，未发现剩余重要问题。

完整套件末尾还有一个历史正例直接将三页 PDF 的 page tree `/Count 3` 改成 `/Count 2`，并未生成合法两页文档。旧提取器容错恢复第三页，新页面渲染按声明只显示两页，第三页配图实际缺失。因此将此例更正为损坏文档应被拒绝，保留生产检查；没有补图掩盖缺页或放宽验证。

## 实际交互与原生结果

本次 UI 模拟项目通过公开 CLI 登记版本，真实浏览器产生反馈和批准：方案 v1→v3、第一章 v1→v2、第二章、单图 v1→v2、图集合、合稿 v1→v2。旧页面批准被拒绝；偏好不会批准对象；重启后恢复当前版本。无图决定在独立副本确认。390px 视口下实测页面宽度与内容宽度同为 390px，版本对比为单列。

最终通过公开 CLI 回读：已确认合稿的样例下一步为 `export`；改成无图后的副本下一步为 `revise manuscript`，要求同步重审合稿，没有沿用旧合稿批准。两个本地审阅服务已在检查结束后停止。

短 UI 样例停在已确认合稿后的 delivery 阶段，不冒充已导出的交付包。完整原生交付由既有 `验收/协作写作-v2-模拟` 证明；本次新增五页 WPS 样例源稿及 DOCX/PDF 保存在 `tests/fixtures/native-longform/`，逐页检查目录、分节页码、正文与图片，无观察到的裁切或重叠。这些证据分别覆盖对应环节，不拼接成一次真实客户验收。
