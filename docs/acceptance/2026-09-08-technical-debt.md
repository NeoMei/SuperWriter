# SuperWriter 技术债修复

基于已发布的 `v0.2.2`，本次处理安装并发写入保护、持续集成覆盖和版本号维护。WPSComposer 的实现与系统适配不在本次范围。

## 安装边界

旧安装器先复制整个宿主 `skills` 目录，再整体替换。已在临时 HOME 中复现：复制后由其他工具更新的无关 skill 文件被还原，新增文件被删除，而安装器仍返回成功。

修复后仅更新受管理的 skill 条目，保留宿主根目录及无关条目身份；同一 HOME 的 SuperWriter 安装进程互斥；失败时按受管理条目回滚。对安装期间改变的 Codex 路由应报告冲突并保留外部修改，而不是静默覆盖。

## 持续集成与版本号

- 四组原生 Python 回归保留。完整 `tests/test_verify_artifacts.sh` 另外在 macOS / Python 3.13 CI 中运行，Windows 原生回归不依赖 Bash。
- `SUPERWRITER_VERSION` 是可执行检查逻辑的版本来源。公开 SKILL 与依赖清单仍作为独立声明交叉核对，保留严格 frontmatter 校验。
- 测试读取版本来源或夹具中的声明，不再重复硬编码当前版本；未来版本回归同时验证正确版本通过、旧版本拒绝。

## 本地维护

本机已有 CodeGraph 索引的排除配置补充工作树、临时工作目录及虚拟环境；先备份配置，再重建索引。此操作只维护已经启用的本地索引，不为其他用户自动开启索引。

本机三个宿主的旧 SuperWriter 副本在升级前单独备份。升级只替换 SuperWriter 自身，按文件摘要核对安装结果，并从安装目录运行临时中文项目的 CLI 与 HTTP 审阅服务。默认系统 Python 3.9 不满足项目要求，因此使用独立 Python 3.13 环境，不替换系统解释器。

验证结果以本分支实际测试和 CI 记录为准；本次修复不创建新的发行版本，也不自动修改已有 Git 标签。

## 本地验证记录

- Python 3.13 全量回归：252 项，250 项通过，2 项 Windows 专属跳过。
- 安装专属回归覆盖无关文件并发写入、原生进程互斥、路由冲突、安装失败及恢复备份；五个信号边界与回滚期间 SIGTERM 检查通过；路由备份前、发布空隙及发布后的修改均有回归，恢复备份使用不覆盖已有文件的操作。
- 三个真实宿主升级到已发布的 0.2.2，文件摘要一致；分别执行中文偏好事件（revision 0 → 1，批准数仍为 0）、HTTP 200 与中文 SVG 转 PNG 检查。旧版备份保留在本机用户数据目录。
- 本地索引重建后由 3,302 个文件缩减到 55 个源码文件，安装器检索不再包含虚拟环境或工作树。
