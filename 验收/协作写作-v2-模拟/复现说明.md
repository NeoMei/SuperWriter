# 协作写作 v2 模拟包复现说明

本目录只包含 synthetic-test 数据，所有确认均为模拟证据，不代表真实客户或真实用户验收。

- `协作状态.json`：通过 CLI/store 生成的最终 revision 63 状态，`delivery` 为 `verified`。
- `验收清单.json`：严格 v2 清单，绑定同目录当前状态、合并稿、章节、配图和原生输出。
- `record-delivery.json`：第一次完整验收 PASS 后由 agent 通道提交的精确机器回执。
- `evidence/`：实际 installed-skill 响应、每阶段状态、浏览器、原生 WPS、双 PASS、原子 revision 刷新、幂等回放和漂移拒绝证据。
- `reproduction/`：生成该模拟流程、配图和 WPS 文件时使用的脚本快照。脚本中的绝对 scratch 路径是原始执行证据，不应直接当作其他客户项目命令。

在当前 SuperWriter 源码根验证持久副本：

```bash
python3 scripts/verify_acceptance.py "$(pwd)/验收/协作写作-v2-模拟"
bash scripts/verify.sh --acceptance-dir "$(pwd)/验收/协作写作-v2-模拟"
```

隔离宿主安装通过 Python `subprocess` 环境字典传入配置，实际非敏感值保存在 `evidence/isolated-env.json`。不要把该临时 HOME 路径视为真实宿主安装。
