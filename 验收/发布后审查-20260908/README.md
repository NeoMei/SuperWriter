# 发布后审查模拟证据

所有输入、反馈与批准均为 synthetic-test，不是客户材料或真实用户验收。

UI模拟项目通过公开 CLI 建立版本，并在真实浏览器操作偏好、修改和确认。当前保留的是已确认合稿后的 delivery 阶段，尚未为这一短UI样例生成正式交付，不应将其视作已完成交付包。

另行使用实际 WPSComposer 生成并逐页检查五页文档，原生源文件/产物保存在 `tests/fixtures/native-longform/`；原有完整 v1/v2 交付样例已用修复后的验证器重新验收。各类证据分别证明其对应环节，报告不把它们冒充一组真实客户端到端验收。

日志包含先失败后通过与独立复审。带临时目录的脚本是调查记录，重放前需显式传入当前 checkout；不要使用其中旧工作树路径作执行入口。

归档日志仅可能裁去行尾空白，以符合仓库差异格式检查；诊断文本和通过/失败结果不变。
